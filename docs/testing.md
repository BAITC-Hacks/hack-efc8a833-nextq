# Проверки качества

Правила синтетического каталога проверяются в `src/data/city-v1.test.ts`, включённом в `pnpm test`.

| Объект | Проверяемое правило |
| --- | --- |
| Районы | Ровно шесть районов с уникальными ID |
| Население | Сумма населения районов равна 100 |
| Начальные показатели | Среднее пяти показателей каждого района равно 50 |
| Мероприятия | Все ID уникальны; в каждом направлении ровно три мероприятия |
| Бесплатные варианты | В каждом направлении есть вариант с нулевой стоимостью без изменения показателей |
| Синергии | Есть хотя бы одна пара; каждая пара ссылается на два существующих ID мероприятий |
| Порядок синергий | ID внутри пары строго возрастают при строковом сравнении; пары не повторяются |

Для локального запуска нужны Node.js 22 и pnpm 10.34.5:

```sh
corepack prepare pnpm@10.34.5 --activate
corepack enable
pnpm install --frozen-lockfile
pnpm test
pnpm lint
pnpm build
```

Только проверки каталога:

```sh
pnpm exec tsx --test src/data/city-v1.test.ts
```

Workflow `.github/workflows/verify.yml` запускает установку по lockfile, все тесты, ESLint и production-сборку на Node.js 22 при push и pull request.
