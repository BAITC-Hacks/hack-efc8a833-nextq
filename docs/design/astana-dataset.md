# Датасет пользователя: основной контракт astana-1

Заменяет прежние условия Qala Lab: 5 районов, 10 показателей, 14 мер, бюджет 100, фиксированный горизонт 8 кварталов. OPEX и горизонты 3/12/36 месяцев не применяются. Числа получены от пользователя как входные данные симулятора; независимая статистическая верификация не заявляется.

## Правила и формула

Ровно 5 разных мер, максимум 2 одного направления. Район обязателен для district и запрещён для city. Цена≤100, остаток без бонуса. Любое нарушение отклоняется с причиной, score не рассчитывается. Порядок решений не влияет на результат.

Каждый эффект, включая отрицательный, умножается на (8−лаг)/8. Городские меры действуют в каждом районе. Эффекты и синергии суммируются, затем однократно clip(0,100). Качество D — взвешенная сумма10 индикаторов. D_avg — сумма D × доля населения. Score=0.7 × D_avg+0.3 × min(D)−N_crit, где N_crit — количество район × индикатор строго ниже 40 ПОСЛЕ эффектов. Округлять только отображение.

Контрольный baseline: D_avg=56.8624; weakest=49.18; N_crit=2; Score=52.55768.

Контрольный набор: M7@nura,M8@nura,M10@nura,M12(city),M5@saryarka. Цена 95, D_avg=58.0776, weakest=52.9625, N_crit=0, Score=56.54307, прирост 3.98539. Районные D:63.4275,57.4975,56.3,57.0675,52.9625.

Дешёвый допустимый набор: M9@nura,M11@nura,M10@nura,M12(city),M4@saryarka, цена61.

## Генерация и интерфейс

Основной curated id `astana` воспроизводит таблицу без изменений. Дополнительные curated кейсы winter/heat/growth — явно обозначенные учебные вариации той же модели. AI создаёт только blueprint с 5 известными ID, долями>0, сумма1 (допуск 1e-6), показателями0..100 и ограниченными строками. Цены, лаги, формула, лимит и14мер восстанавливаются сервером. Типы в src/domain/city-case.ts. Старые sandbox/challenge используют старую отдельную модель и не сравниваются с astana-1.

HTTP: GET /api/cases unchanged shape; POST generate {brief,theme?} unchanged shape; POST evaluate/analyze теперь {caseId,caseToken?,decisions:[{measureId,districtId?}]} БЕЗ horizonMonths. Evaluation использует result.baselineAqol/finalAqol (Score),10индексов,contributions,synergies,criticalCount. Сравнение только одинаковый caseId/caseVersion. AI объясняет вычисленные числа, не вычисляет их.
