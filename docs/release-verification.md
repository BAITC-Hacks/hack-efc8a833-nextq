## Контрольный пример пользователя

M7, M8, M10 в Нуре; M12 по городу; M5 в Сарыарке. Цена 95, остаток 5. Baseline 52.55768, итог 56.54307, прирост 3.98539. Средневзвешенное качество 58.0776, слабейший район 52.9625. Критических показателей 2→0; синергия M10+M12 добавляет B1+2 в Нуре. Значения также независимо перепроверены прямым вычислением по таблице.

## Браузер

Проверены каталог и повторная загрузка после ошибки, пять решений, запрет недопустимого набора, повтор расчёта после HTTP 503, AI-ready/unavailable, сохранение двух планов, сравнение, восстановление полного отчёта после reload, JSON-download. Новый расчёт очищает старый отчёт; поздний ответ генерации не заменяет уже открытый кейс. На ширинах 320/768/1440 отчёт не расширяет страницу; широкая таблица прокручивается внутри контейнера. Есть клавиатурный переход к содержимому.

WebGL-сцена действительно отрисована в Chromium. При искусственно отключённом WebGL интерфейс показывает альтернативу и позволяет получить тот же Score. Печать отдельно проверена созданием PDF. Browser E2E подменяют AI-ответы и не тратят токены; живой прогон отдельно создал новый подписанный зимний кейс, вычислил план и получил AI-разбор без JS-ошибок.

## Ревью

Независимый агент обнаружил гонку завершения генерации и неполное сохранение отчётов. Обе ошибки исправлены; повторное ревью подтвердило исправления. Восстановление сохранения валидирует blueprint/решения и пересчитывает оценку по доверенному каталогу; сохранённые клиентские score/cost не являются источником расчёта.

## Границы проверки

Публичный registry, внешний Kubernetes, Ingress/TLS и многопользовательская авторизация не проверялись и не входят в текущий комплект. Лимиты AI действуют в одном процессе; для открытого масштабируемого сервиса нужен общий контроль доступа и квот. Данные и причинные эффекты не калиброваны по официальной городской статистике. Численный результат проверен, естественно-языковой ответ LLM остаётся пояснением к нему.

Тестовые Docker-контейнер и отдельный namespace `akim-release-smoke` удаляются после smoke. Локальный production-сервер для просмотра запускается отдельно.

В [PR №3](https://github.com/BAITC-Hacks/hack-efc8a833-nextq/pull/3) GitHub Check Runs `verify` и `delivery` завершились до запуска шагов: «The job was not started because your account is locked due to a billing issue». Требуется исправление биллинга владельцем организации и повторный CI-прогон. Локальные результаты выше не выдаются за успешный GitHub Actions.
