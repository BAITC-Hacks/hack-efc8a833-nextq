# Аким на 5 часов

AI-симулятор управления условным городом. За пять решений команда распределяет общий виртуальный бюджет между транспортом, зелёными зонами, социальной инфраструктурой, безопасностью и городскими сервисами.

Каждая команда начинает с одинаковых синтетических данных и бюджета. Система проверяет стоимость выбранных мероприятий, рассчитывает изменение показателей и формирует Astana Quality of Life Score (AQoL) с AI-объяснением сильных сторон, рисков и компромиссов.

## Запуск

Требуется Node.js 22.x и pnpm.

```sh
pnpm install
pnpm dev
```

Откройте `http://localhost:3000`.

Production-сборка:

```sh
pnpm build
pnpm start
```

Тесты доменной модели:

```sh
pnpm test
```

## Модель города

Каталог `src/data/city-v1.ts` содержит шесть вымышленных районов, 15 мероприятий и одну синергию: парк и освещение в одном районе дополнительно повышают безопасность на 2 пункта. Версии набора и правил — `city-1` и `rules-1`; общий бюджет — 100 условных единиц. Население задано в тысячах. Все показатели используют шкалу 0–100, где больше означает лучше.

Сначала суммируются эффекты пяти решений и синергии, затем показатели ограничиваются диапазоном 0–100. Качество района — среднее пяти показателей. Итоговый `AQoL = 0.8 × среднее качество с весами по населению + 0.2 × качество слабейшего района`. Расчёт сохраняет полную точность. Коэффициенты являются игровыми допущениями, а не прогнозом для реальной Астаны.

Домен проверяет версии, пять разных направлений, соответствие мероприятий направлениям, существование районов и лимит расходов. Цены и эффекты берутся из каталога. `runScenario` связывает каталог с чистым доменным расчётом; зависимости от UI, HTTP и AI отсутствуют.

Контрольные сценарии с инициативами в Оркене:

| Решения | Расход | AQoL |
| --- | ---: | ---: |
| Все пять бесплатных | 0 | 50.000 |
| Приоритет автобусов; остальные бесплатные | 20 | 50.160 |
| Автобусы, карманные парки, общественный центр, освещение, цифровое окно | 85 | 50.944 |
| Расширение дороги, зелёный коридор, общественный центр, камеры, выездной центр услуг | 121 | Отклонён |

Полный допустимый сценарий изменяет показатели Оркена на `[11, 10, 14, 12, 12]` в порядке транспорт / зелень / соцсфера / безопасность / сервисы. Освещение даёт дополнительный пункт транспорту.

Проверяются контрольные сценарии, точный лимит бюджета, синергия только в одном районе, оба ограничения шкалы, порядок суммирования, вес населения, слабейший район, неизменность входов и некорректные решения.
